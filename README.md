# Message Hub

## День 1. Описание задачи

Разработать программу автоматического сбора и разбора входящих текстовых сообщений и новых публикаций из подключённых источников.

Статус: обсуждение и согласование требований. Разработка программы пока не начата.

## Источники

- Telegram: каналы и личные сообщения.
- WhatsApp: каналы и личные сообщения.
- E-mail: входящие сообщения из нескольких почтовых ящиков.
- RSS: публикации из подключённых лент.
- ВКонтакте: личные сообщения, публикации сообществ, записи друзей и комментарии.
- YouTube: только названия и описания видео, если описания есть. Комментарии и расшифровки не обрабатываются.

Предусмотреть подключение новых источников через модули без переработки основной программы.

## Автоматический разбор

- Краткое содержание сообщения или публикации.
- Определение темы и распределение по категориям.
- Выделение вопросов, задач и сроков, если они указаны.
- Оценка срочности.
- Поиск материалов по заданным интересам.
- Сохранение результатов в едином списке с указанием источника, автора, даты и ссылки на оригинал, когда эти сведения доступны.

## Границы первого этапа

Обрабатывается только текст. Вложения, изображения, голосовые сообщения, аудио и видео не анализируются. Расшифровки YouTube пока не используются.

## Требует дальнейшего обсуждения

- Способы подключения и ограничения каждого сервиса. Перечень выше описывает желаемый охват, техническая доступность ещё не проверена.
- Список аккаунтов, каналов, сообществ и лент.
- Темы интересов и правила оценки срочности.
- Частота сбора, хранение результатов и интерфейс.

В публичном репозитории размещаются описание проекта и в дальнейшем код. Личные сообщения, содержимое почтовых ящиков и данные доступа сюда не публикуются.
