# Message Hub

Локальная система обработки входящей текстовой информации и планирования рабочих и личных задач.

## Состояние на 14 сентября 2026 года

Подготовлены демонстрационный прототип семи экранов и локальная версия подключения нескольких Gmail-ящиков: SQLite, сбор новых писем, общий список и история открытий. Для реального подключения нужны настройка Google и вход пользователя в каждый аккаунт. Реальные Gmail-аккаунты пока не подключены. ИИ, календарь, автозапуск и автоматическое резервное копирование ещё не реализованы.

## Запустить локальную версию Gmail

После установки зависимостей в окружение Python 3.12:

```sh
.venv/bin/python -m message_hub.server
```

Браузер откроется автоматически. Инструкция по установке, настройке Google, подключению нескольких ящиков и ограничениям — [GMAIL_SETUP.md](docs/GMAIL_SETUP.md). Для разработки используется отдельное хранилище: `--data-dir .local-data`.

## Открыть прототип

Откройте `prototype/dist/index.html` в браузере. Он работает без установки зависимостей и без подключения к интернету.

Либо из корня проекта запустите:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory prototype/dist
```

Затем откройте http://127.0.0.1:8765 в браузере. Завершение сервера — Ctrl+C.

Все сообщения, имена и события внутри прототипа вымышлены. Дата демонстрации фиксирована: 10 сентября 2026 года. Данные живут в памяти страницы: обновление страницы или кнопка «Сбросить демонстрацию» возвращает исходные примеры.

## Основные принципы

- Только новые сообщения после подключения; после сна — догрузка доступного пропущенного.
- Все доступные материалы согласованных типов из Telegram, WhatsApp, E-mail, RSS, ВКонтакте и YouTube. Технические возможности каждого источника ещё требуют проверки.
- Краткое содержание, сферы интересов, важность 1–5 и срочность по сроку/отправителю.
- Задачи и переносы попадают в календарь после решения пользователя.
- Работа под отдельным пользователем macOS, перенос на другой компьютер и резервное копирование предусмотрены в требованиях.

В репозитории хранятся документация и демонстрационный код. Реальные сообщения, почта, ключи и данные доступа не публикуются.
